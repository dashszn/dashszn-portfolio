- Fake achievements
- Public CGPA

- Backend API

- Overcomplicated animations

The website should be:

- Professional
- Friendly

- Easy to understand
- Suitable for recruiters and non-technical visitors

Work only on the requested sprint or issue. Do not expand the project scope without explicit approval.
