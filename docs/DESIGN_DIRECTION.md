# Design Direction — Dashszn.dev

## Visual Goal

Dashszn.dev should feel modern, clean, futuristic, and professional without becoming confusing or overly technical.

## Design Keywords

- Clean
- Modern
- Calm
- Futuristic
- Friendly
- Professional
- Minimal
- Premium
- Accessible

## User Experience Rule

Navigation and section names must be easy to understand for both technical and non-technical visitors.

## Preferred Sections

- Home
- About
- Skills
- Experience
- Education
- Direction
- Projects
- Contact

## Visual Style

- Dark theme preferred
- Soft gradients
- Clean cards
- Rounded corners
- Good spacing
- Subtle animations
- No excessive neon
- No clutter
- Mobile-first responsive layout

## Accessibility

- Text must be readable
- Color contrast must be acceptable
- Navigation must be clear
- Buttons and links must be obvious
