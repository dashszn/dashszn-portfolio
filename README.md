# Dashszn.dev

Dashszn.dev is the personal website of Danish Syazani, also known as Dash.

This project is designed as a modern, compact, and professional personal profile website that presents Danish's background in software engineering, full-stack development, AI curiosity, creative technology, and long-term career direction.

## Project Status

Current phase: Sprint 0 — Blueprint & Documentation

## V1 Scope

Dashszn.dev v1 will include:

- Home
- About
- Skills
- Experience
- Education
- Direction
- Projects & Lab
- Contact

V1 will not include fake project placeholders, public CGPA, phone number, unfinished project claims, certificates not yet provided, authentication, database, or admin dashboard.

## Tech Stack Planned

- Astro
- React
- TypeScript
- Tailwind CSS
- pnpm
- GitHub Pages
- Cloudflare Pages
